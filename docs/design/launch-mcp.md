# 起動の窓口（MCP）

- 対象: 段階3
- 状態: **概要のみ**。PoC（P1）と段階2の結果で詳細を書く
- 最終更新: 2026-10-04
- 関連: [ADR-0003](../adr/0003-focus-interruption-strategy.md)（3層で防ぐ方針。この機能は「正規の起動手段」の層）、[フォーカスガード](focus-guard.md)

Codexに、アプリを安全に起動して確かめるための道具を渡す機能。「GUIを起動するな」と禁じる代わりに、「この方法で確かめて」と道を用意する。

## 1. 概要

- 別のexe（`monitoringai-mcp.exe`、stdio のMCPサーバー）を用意し、Codexの `config.toml` に登録する。常駐アプリとは名前付きパイプで通信する。
- ツール: `launch_app`、`screenshot`、`close_app`、`app_status`。
- 起動できるのは、**ワークスペースごとの許可リストにあるコマンドだけ**とする。任意のコマンドは受け付けない。
- 起動先: P1が成功したら隠しデスクトップ。失敗したら画面外への配置か、段階2のガードで抑える。
- 起動ルール: すぐ起動する、ユーザーが操作していない間だけ起動する（`GetLastInputInfo`）、毎回確認する。トレイで切り替える。
- **AIが指示を守らなくても防げるように、必ず[フォーカスガード](focus-guard.md)と組み合わせる。** この機能だけでは、AIがコマンドを直接実行すれば迂回される。
