# 技術選定の記録（ADR）

このフォルダには、MonitoringAI の技術的な決定と、その理由を1件ずつ残す。
「何をどう作るか」は [設計書](../DESIGN.md) に書き、ここには「なぜそうしたか」「他に何を検討したか」を書く。

## 書き方

- 1件の決定につき1ファイル。ファイル名は `NNNN-短い名前.md`。
- 一度「承認」にした内容は書き換えない。決定を変えるときは新しいADRを作り、古いADRの状態を「置き換え済み（→ NNNN）」にする。
- 追記してよいのは、「結果の記録」の節（測定値など、決定のときには不明だった事実）だけとする。
